# Example: Cantilever Beam Deflection

A synthetic surrogate-modeling problem: predict the tip deflection of a cantilever beam under a
point load from its geometry, load, and material, given noisy "simulation" data generated from
the analytic formula `delta = P * L^3 / (3 * E * I)`.

## Dataset

Fully synthetic, generated by [`generate_data.py`](generate_data.py) — no proprietary or
third-party data. Source: this repository. License: MIT (same as the rest of the project).
Intended use: demonstrating and testing surrogate-lab's training and reporting pipeline.
Limitations: it is not a substitute for real simulation data — it captures one closed-form
analytic relationship plus Gaussian noise, not the full physics of beam bending (e.g. no shear
deformation, no material nonlinearity).

Columns:

- `length_m`: beam length, 0.5-3.0 m
- `load_n`: point load at the tip, 50-2000 N
- `moment_of_inertia_m4`: second moment of area of the cross-section, 1e-7 to 5e-6 m^4
- `material`: `steel`, `aluminum`, or `composite` (categorical; sets the elastic modulus)
- `deflection_m`: tip deflection in meters (target)

## Run it

From the repository root, with the dev environment installed (see the top-level README's
quickstart):

```bash
.venv\Scripts\python examples\beam_deflection\generate_data.py
.venv\Scripts\surrogate-lab train examples\beam_deflection\config.yaml
```

(On macOS/Linux, use `.venv/bin/python` and `.venv/bin/surrogate-lab`.)

This trains linear regression, random forest, and gradient boosting models, 5-fold
cross-validates each, and writes:

- `examples/beam_deflection/outputs/models/<model>.joblib` (+ `.meta.json`) — one fitted pipeline
  per model.
- `examples/beam_deflection/outputs/report.html` — a single self-contained HTML report with a
  metrics comparison table and, per model, a parity plot (with prediction-interval band), a
  residual plot, and a residual histogram.

Then predict on the same data with a saved model:

```bash
.venv\Scripts\surrogate-lab predict examples\beam_deflection\outputs\models\random_forest.joblib examples\beam_deflection\data.csv examples\beam_deflection\outputs\predictions.csv --interval
```
